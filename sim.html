Microscopic Traffic Flow Simulation

A Python-based study on the Intelligent Driver Model (IDM)

Abstract. This project simulates highway traffic flow to observe the emergence of "phantom traffic jams"—jams that appear without a bottleneck, caused purely by driver reaction times and braking waves.

1. The Mathematical Model

To simulate realistic car-following behavior, I utilized the Intelligent Driver Model (IDM). The acceleration $\dot{v}$ of a vehicle $\alpha$ is given by the differential equation:

$$ \dot{v}_\alpha = a \left[ 1 - \left( \frac{v_\alpha}{v_0} \right)^\delta - \left( \frac{s^*(v_\alpha, \Delta v_\alpha)}{s_\alpha} \right)^2 \right] $$

Where $v_0$ is the desired velocity, $s_\alpha$ is the actual gap to the car in front, and $s^*$ is the desired minimum gap, calculated as:

$$ s^*(v, \Delta v) = s_0 + v T + \frac{v \Delta v}{2\sqrt{ab}} $$

This allows the agent to brake intelligently when approaching a slower vehicle ($ \Delta v > 0 $).

2. Implementation

The simulation uses an Agent-Based Modeling approach. Each vehicle is an object with state variables $(x, v, a)$. 

class Vehicle:
    def update(self, lead_vehicle, dt):
        """
        Updates velocity and position based on IDM.
        """
        delta_v = self.v - lead_vehicle.v
        s = lead_vehicle.x - self.x - lead_vehicle.length
        
        # Calculate desired gap term
        s_star = self.s0 + (self.v * self.T) + \
                 (self.v * delta_v) / (2 * np.sqrt(self.a * self.b))
        
        # Calculate acceleration
        acc = self.a * (1 - (self.v / self.v0)**4 - (s_star / s)**2)
        
        # Euler integration
        self.v += acc * dt
        self.x += self.v * dt
